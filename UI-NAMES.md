# UI names

Use these names and Claude will know exactly what you mean. Each link opens Apple's page for it, with pictures.

To see all of them: [Apple's full components list](https://developer.apple.com/design/human-interface-guidelines/components). For live versions you can click, open Apple's macOS kit in Figma. Add your own names at the bottom.

## Buttons

| Name | What it is | Apple's page |
|---|---|---|
| Push button | The normal rounded button | [Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons) |
| Prominent button | The filled, colored main action, like Done | [Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons) |
| Image button | A button that's just an icon | [Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons) |
| Help button | The small round "?" | [Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons) |
| Pop-up button | Pick one option from a list, and it shows your choice | [Pop-up buttons](https://developer.apple.com/design/human-interface-guidelines/pop-up-buttons) |
| Pull-down button | Opens a list of actions, and its label stays the same | [Pull-down buttons](https://developer.apple.com/design/human-interface-guidelines/pull-down-buttons) |
| Disclosure triangle | The small arrow that shows or hides a section | [Disclosure controls](https://developer.apple.com/design/human-interface-guidelines/disclosure-controls) |
| Disclosure button | The small chevron button that expands more options | [Disclosure controls](https://developer.apple.com/design/human-interface-guidelines/disclosure-controls) |

## Choosing and typing

## Pop-ups and dialogs

| Name | What it is | Apple's page |
|---|---|---|
| Alert | A small box in the middle asking you to decide, like "Save changes?" | [Alerts](https://developer.apple.com/design/human-interface-guidelines/alerts) |
| Sheet | A card over a window that blocks it until you finish, like Export | [Sheets](https://developer.apple.com/design/human-interface-guidelines/sheets) |
| Popover | A small bubble with a pointer, attached to what you clicked | [Popovers](https://developer.apple.com/design/human-interface-guidelines/popovers) |
| Panel | A small floating helper window, like Fonts or Colors | [Panels](https://developer.apple.com/design/human-interface-guidelines/panels) |
| Notification | The system's banner in the corner of the screen | [Notifications](https://developer.apple.com/design/human-interface-guidelines/notifications) |

## Windows and layout

| Name | What it is | Apple's page |
|---|---|---|
| Title bar | The top strip of a window | [Windows](https://developer.apple.com/design/human-interface-guidelines/windows) |
| Window controls | The red, yellow and green dots, often called traffic lights | [Windows](https://developer.apple.com/design/human-interface-guidelines/windows) |
| Toolbar | The row of tools at the top of a window | [Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars) |

| Inspector | The settings column for whatever is selected | [Split views](https://developer.apple.com/design/human-interface-guidelines/split-views) |

| Scroll bar | The bar that shows and drags your scroll position | [Scroll views](https://developer.apple.com/design/human-interface-guidelines/scroll-views) |
| Box | A lightly outlined group of related controls | [Boxes](https://developer.apple.com/design/human-interface-guidelines/boxes) |

## Names in Untitled

These are the names we use. They aren't Apple's terms.

| Name | What it is |
|---|---|
| Thumbnail stack | The captures floating in the corner |
| Hover buttons | Copy, close, pin and delete on a thumbnail while you hover |
| Toast | The notice at the top of the screen after copying text |
| Capture overlay | The dimmed screen while you drag out an area |
| Canvas | The image area in the editor |
| Mark | Anything drawn on the image: arrow, shape, highlight, and so on |
| Status bar | The zoom and image size controls under the canvas |
| Handles | The dots for resizing or reshaping a mark |
| Pinned image | A capture floating on top of your other windows |
